  q.dtype == k.dtype == do.dtype == torch.bfloat16. So the FP16 backward
  parallel state path is currently unreachable even though PR #42 added a

  no cu_seqlens, HQ==H, not state_v_first, g/g_gamma/gv None, gk not None.
