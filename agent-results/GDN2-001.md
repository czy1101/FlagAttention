# GDN2-001: independent small-sequence reference on Enflame

## Result

The independent, CPU FP64 token recurrence in `tests/flag_attn/gdn2_tiny_reference.py` agrees with the Enflame `chunk_gdn2` inference path for 12 tested combinations: T=1, 2, 65; FP16 and BF16; with and without `initial_state`. Every case uses B=H=1, K=V=64, seed 0, and checks both output `o` and final state `ht`. T=65 crosses the 64-token chunk boundary. The full run exited 0 and its output is preserved in `agent-results/GDN2-001-full.log`.

The reference applies per-channel `exp(g)` decay, then the delta-rule erase/write, then reads the post-update state. It compares FP64 CPU results with the device outputs after casting inputs to the tested dtype. The gate requires max absolute error <= `1e-3 + 2e-2 * reference_RMS` and relative RMS error <= 2e-2 for both `o` and `ht`.

At T=65, FP16 relative RMS errors were at most 5.18e-4 for `o` and 4.06e-4 for `ht`; BF16 errors were at most 4.23e-3 for `o` and 3.03e-3 for `ht`.

## Reproduce

From this clone inside `zwj-enflame-vllm`, with container GCU 0 (host GCU 4):

```bash
PYTHONPATH="$PWD/src:/opt/flagtree" /flagos/bin/python tests/flag_attn/gdn2_tiny_reference.py 1,2,65
```

The company DeepSeek harness prepared the initial reference script on its isolated branch. Its run reached the time limit before committing; the reviewer added no-initial-state cases, reran the complete suite, and committed this report and raw output.

## Limits

This validates the stated recurrence at one seed and small sequences, including a chunk boundary. It does not cover gradients, larger batch/head counts, optional gate transformations, packed sequences, or performance. The original native Triton comparison at a larger shape timed out, so no whole-operator or speedup claim follows from this test.
